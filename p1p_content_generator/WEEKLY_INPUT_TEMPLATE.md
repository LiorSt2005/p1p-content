# Template de Solicitação Semanal — P1P Content Generator

## Como usar

Cole o bloco abaixo no chat do Claude Project (com o System Prompt configurado) e preencha os campos. O agente gera o conteúdo completo pronto para edição e publicação.

---

## Bloco de Solicitação (copie e preencha)

```
FORMATO: [LinkedIn Post / Carrossel / Reel / Facebook / Landing Page]
AUDIÊNCIA: [BI / BPO]
TEMA: [descreva o assunto em uma frase]
ÂNGULO: [opcional — ex: "foco no erro mais comum", "tom de diagnóstico", "baseado em framework"]
DADO OU VINHETA: [opcional — ex: "inclua uma vinheta de escritório de advocacia"]
SEMANA: [opcional — ex: Semana 1 do plano]
```

## Workflow Semanal Recomendado

| Dia | Ação | Tempo |
|---|---|---|
| Segunda | Abrir o Claude Project, preencher 2–3 blocos de solicitação (LinkedIn + Carrossel da semana) | 10 min |
| Segunda/Terça | Revisar e editar os drafts gerados | 30–40 min |
| Terça | Montar o carrossel no Canva usando o roteiro | 45–60 min |
| Quarta | Agendar posts (Buffer, Later ou Meta Business Suite) | 15 min |
| Sexta | Revisar métricas, anotar o que performou melhor | 15 min |
| **Total** | | **~2h/semana** |

## Dicas de Edição Rápida

1. **Hook:** É o elemento mais importante — sempre teste a primeira linha em voz alta. Se não parar seu próprio scroll, reescreva.
2. **Carrosseis:** Cada slide deve funcionar sozinho como uma frase de impacto. Se precisar do slide anterior para entender, simplifique.
3. **CTA:** Nunca "Entre em contato" ou "Acesse o site" soltos. Sempre contextualize: "Se você reconhece esse cenário no seu escritório, vale uma conversa sem compromisso."
4. **Hashtags LinkedIn:** Use no máximo 5. Prefira: `#BusinessIntelligence #PowerBI #GestãoEmpresarial #BPO #ConsultoriaEstrategica`
